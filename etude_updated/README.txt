# ЭТЮД — сайт журнала МХПИ

## Как посмотреть
Откройте `index.html` в браузере. Для публикации загрузите **все содержимое папки** `etude_site` на статический хостинг (например, GitHub Pages или Netlify).

## Страницы
- `index.html` — главная
- `issues.html` — архив выпусков
- `issue-01.html` — пилотный выпуск
- `community.html` — сообщество и доска объявлений
- `contacts.html` — контакты

## Как редактировать
Откройте нужный `.html` файл в любом редакторе кода (например, VS Code).
- Тексты находятся непосредственно в HTML.
- Фотографии лежат в `assets/`. Чтобы заменить фото, положите новый файл в `assets/` и измените путь `src="assets/..."` в HTML.
- Цвета, шрифты, размеры и адаптивность редактируются в `styles.css`.
- Меню, переключение темы и открытие фото — в `script.js`.

## Что пока ожидает ссылку
- Бот редакции: в `contacts.html` пока стоит неактивная кнопка-заглушка.
- Чат «Нужна натура»: ссылка пока не предоставлена.
- Чат по интересам отмечен как находящийся в разработке.

## Примечание
Тема день/ночь запоминается в браузере. Все фотографии журнала открываются в увеличенном просмотре по нажатию.


ОБНОВЛЕНИЯ ПРОТОТИПА
- Фотографии каждой истории открываются отдельной галереей; можно листать кнопками, стрелками клавиатуры и свайпом на телефоне.
- Плашка «НОВОЕ» скрывается автоматически через 7 дней от даты, указанной в data-new-until (сейчас дата выпуска 23.11.2026). Для нового материала поменяйте дату окончания на дату публикации + 7 дней.
- Лайк/дизлайк в этой демонстрационной версии сохраняется в браузере посетителя. Это не общий счётчик для всех посетителей; для общей статистики потребуется подключить базу данных или сервис голосования.
- Фильтры пока не добавлялись.

Уточнение 23.11.2026: реакции теперь относятся ко всему выпуску, размещены в начале статьи и внизу. Повторное нажатие на выбранную реакцию снимает её; лайк анимируется пульсацией, дизлайк — раскалыванием сердца. Логотипы автоматически переключаются: чёрный в светлой теме, белый в тёмной.


Обновление реакций: на одном браузере/устройстве хранится только одна активная реакция на выпуск. Выбор сохраняется после обновления страницы и синхронизируется между верхним и нижним блоком; смена лайка на дизлайк заменяет прежний голос, а повторное нажатие снимает его. Локальный счётчик не является общим счётчиком всех посетителей.


ОБЩИЙ СЧЁТЧИК РЕАКЦИЙ — ТРЕБУЕТ ПЕРВИЧНОГО ПОДКЛЮЧЕНИЯ

В архив добавлены:
- netlify/functions/reactions.js — серверный API для чтения/записи голосов;
- supabase_setup.sql — SQL для создания таблицы;
- netlify.toml — настройка публикации Netlify Functions.

Чтобы общий счётчик заработал:
1. Создайте проект в Supabase (supabase.com).
2. Откройте SQL Editor в проекте, вставьте весь текст файла supabase_setup.sql и нажмите Run.
3. В Supabase откройте Project Settings → API. Скопируйте Project URL и service_role key (секретный ключ; не публикуйте его и не вставляйте в HTML/JavaScript).
4. В Netlify откройте сайт → Site configuration → Environment variables. Добавьте:
   SUPABASE_URL = ваш Project URL
   SUPABASE_SERVICE_ROLE_KEY = ваш секретный service_role key
5. Сохраните переменные и запустите новый Deploy (повторно загрузите содержимое этой папки либо запустите redeploy).

До добавления переменных окружения общий счётчик не будет работать — интерфейс покажет сообщение о том, что сервер реакций не подключён.
После настройки сервер хранит одну запись на пару «выпуск + ID браузера». Повторная загрузка страницы не добавляет голос повторно; выбор можно заменить или удалить. Верхний и нижний блоки читают один и тот же серверный счётчик.

Важно: идентификатор устройства хранится в localStorage браузера. Очистка данных сайта, приватный режим или другое устройство создадут новый ID. Это практическое ограничение анонимного голосования без входа в аккаунт; это не защита от намеренной накрутки. Для строгого ограничения голосования нужна авторизация/проверка пользователя или антибот-защита.
